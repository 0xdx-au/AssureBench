Scan safety and coverage

The archive is path-validated, extracted into a private temporary folder, mounted read-only in pinned containers, and deleted when the scan ends. Scanners have network access for rules and vulnerability data. Project commands are not executed.

Checks include SAST, secrets, dependencies, IaC, SBOM, GitHub Actions, shell scripts, architecture inference, and framework evidence mapping. Dynamic and live-deployment checks are outside this source scan.
